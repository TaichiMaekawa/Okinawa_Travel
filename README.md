# Okinawa_Travel
this is my travel


2026年11/5〜11/9 の沖縄旅行（MONGOL800 フェス参戦）の移動を、古地図の上で赤い線が伸びていく演出で見るWebページです。
`index.html` の1ファイルだけで動きます（CSS/JSも中に入っています）。

## 2つの版
| ファイル | 見た目 |
|---|---|
| `index.html` | 冒険版：セピアの古地図・額縁・明朝体 |
| `pop.html` | ポップ版：明るく見やすい地図、丸ゴシック、乗り物は自作SVGの丸いバッジ、ゴールで紙吹雪 |

動き（赤線が伸びる・カードの切り替え・ボタン）は両方とも同じです。ヘッダーのリンクで行き来できます。
**座標・文言のデータは両方のファイルに入っているので、直すときは両方直してください。**

## 起動方法

### いちばん簡単な方法
`index.html` をダブルクリックしてブラウザで開くだけで動きます（`file://` 対応）。

### ローカルサーバーで開く方法
このフォルダ（`旅行アニメ`）で次を実行し、ブラウザで http://localhost:8000/ を開きます。

```bash
python -m http.server 8000
```

止めるときはターミナルで `Ctrl + C` を押します。

※ 地図（Leaflet・地図タイル）とフォントはインターネットから読み込みます。オフラインのときは「地図を読み込めません」と表示されます（時系列カードは表示されます）。

## 操作

| ボタン | 動き |
|---|---|
| ▶ 旅を開始（START） | 再生を始める。再生中は「一時停止／再開」の切り替えになる |
| ↺ リセット（RESET） | 赤線・乗り物・カード・地図位置を最初の状態に戻す |
| 1x / 2x / 4x | 再生速度（再生中でも切り替えられる） |
| ⏭ スキップ | アニメーションを省いて、全ルートを一度に描いてゴールへ |

OSの「視差効果を減らす／アニメーションを減らす」設定が有効な場合は、区間ごとに一度に表示します（URLの末尾に `?reduce` を付けても同じ動きになります）。

## 編集したい場所（`index.html` の `<script>` 内、先頭付近）

| 何を直したいか | 場所 |
|---|---|
| 地点の名前・座標 | `const STOPS = { ... }`。`lat`（緯度）・`lng`（経度）を書き換える。`verified` は確認状況のメモ |
| 地図ラベルの出方 | 各地点の `lvl`（1=常に表示／2=沖縄本島が見える程度で表示／3=那覇市内まで寄ったとき表示）と `dir`（ラベルの向き） |
| 行きたい場所の薄いピン | `const WISHLIST = [ ... ]` |
| 古宇利島一周の形 | `const KOURI_LOOP = [ ... ]`（[緯度, 経度] の並び） |
| カードの文言・時刻・経路 | `const LEGS = [ ... ]`。`title`（見出し）・`time`・`note`（ひとこと）・`warn`（注意）・`segs`（経路。`pts` に地点idか座標を並べる、`mode` は plane / rail / bus / taxi / ferry / bike / walk） |
| 移動手段のアイコン | `const MODES = { ... }` |
| 日ごとの赤線の色 | `const DAY_COLOR = { ... }` |

## 座標の出典
- Googleマップのリンクから読み取った値：渡久地港・美らテラス・アメリカンビレッジ・ゲストハウス海風
- OpenStreetMap Nominatim で確認した値：中部国際空港・那覇空港・県庁前駅・万座毛・水納島（水納港）・古宇利大橋・古宇利島・名護バスターミナル・宜野湾港マリーナ・国際通り・果報バンタ・青の洞窟
- 地区（町名）までしか確認できなかった値：DO PI-CAN（本部町健堅）・おもろまち駅・運天原バス停
- 未検証の近似値：沖縄ワールド（行きたい場所のピンのみ）

## 地図タイル
国土地理院のタイルを使っています（冒険版＝標準地図にセピアのフィルタ、ポップ版＝淡色地図）。APIキー不要で、`file://` で開いても表示されます。
読み込めない場合は自動で Esri の地形図タイルに切り替わります。候補は `const TILE_PROVIDERS = [ ... ]` で変更できます。
※ OpenStreetMap 公式タイルは、Chrome で `file://` から開くと「Access blocked」になるため使っていません（CARTO は API キーが必要）。
